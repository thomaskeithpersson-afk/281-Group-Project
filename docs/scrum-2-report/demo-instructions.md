# Demo Instructions

## Project
BookExchange

## Demo environment
This prototype runs in a localhost environment.

## How to run
1. Clone the repository.
2. Open the project folder locally.
3. Run the application using the team's local setup.
4. Open the relevant localhost page or the main application file in the browser.

## Recommended demo sequence
1. Open the home page.
2. Show available book listings.
3. Open a book details page.
4. Post a new book listing.
5. Open **My Listings**.
6. Delete a listing.
7. Show the **contact seller by email** action.
8. Briefly explain that the login feature is partial and that full authentication is out of scope for this deliverable.

## Important notes for the instructor / audience
- The prototype is demonstrated locally because the team did not purchase hosting or a domain.
- Full authentication, in-app messaging, and peer rating were intentionally out of scope for this project stage.
